# CHIMERA v6 on ten external real web-server traces

Generated by `src/scripts/analyze_ext.py ext`. Workloads: six 100-minute windows of the NASA Kennedy Space Center web server log (July 1995) and four of the ClarkNet log (August-September 1995), both from the Internet Traffic Archive, as built by `dataset/tools/ita_to_traces.py`. Request rates are scaled by 3 (NASA) and 1.5 (ClarkNet) so that the busiest minute fits the 30-replica limit of the horizontal-only baselines at the cheapest sweep setting. The windows were fixed by rule before any controller ran on them and were used in no design round. Main comparison: 900 runs, 10 seeds. Frontier sweep: 3150 runs, 5 seeds. Same protocol as `REPORT_v6.md`: scored window minutes 70-100, 20-minute warm-up, unchanged controller settings.
