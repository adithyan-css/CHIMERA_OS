# CHIMERA v6 on ten production serverless-function traces

Generated by `src/scripts/analyze_ext.py hw`. Workloads: ten functions of the Huawei Private Cloud FaaS trace 2023 (sir-lab/data-release, CC BY 4.0; Joosen et al., SoCC 2023), one 100-minute window each, as built by `dataset/tools/huawei_to_traces.py`. The functions differ in volume by five orders of magnitude, so each window is scaled so that its busiest minute is 12 requests/second, the largest peak the horizontal-only baselines can serve at the cheapest sweep setting. The windows were fixed by rule before any controller ran on them and were used in no design round. Main comparison: 900 runs, 10 seeds. Frontier sweep: 3150 runs, 5 seeds. Same protocol as `REPORT_v6.md`: scored window minutes 70-100, 20-minute warm-up, unchanged controller settings.
