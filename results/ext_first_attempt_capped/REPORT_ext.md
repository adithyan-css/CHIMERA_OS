# CHIMERA v5 on ten external real traces

Generated by `src/scripts/analyze_ext.py`. Workloads: six 100-minute windows of the NASA Kennedy Space Center web server log (July 1995) and four of the ClarkNet log (August-September 1995), both from the Internet Traffic Archive, as built by `dataset/tools/ita_to_traces.py`. The windows were fixed by calendar rule before any controller ran on them and were used in no design round. Main comparison: 900 runs, 10 seeds. Frontier sweep: 4200 runs, 5 seeds. Same protocol as `REPORT_v5.md`: scored window minutes 70-100, 20-minute warm-up, unchanged controller settings. Request rates are scaled by 5 (the Azure excerpts use 15).
